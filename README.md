# YourCoSite

Marknadssajten för YourCoSite — byggd med Next.js (TypeScript) och Tailwind CSS.

## Utveckling

```bash
npm install
npm run dev
```

Sajten körs sedan på http://localhost:3000

## Struktur

- `app/` — sidor (Next.js App Router). Varje undermapp är en sida, t.ex. `app/priser/page.tsx` → `/priser`.
- `components/` — återanvändbara byggblock (header, footer, prisfrågor m.m.).
- `public/images/` — bilder som används på sajten.

## Status

Marknadssidorna (Landning, Funktioner, Priser) är byggda. Övriga sidor (Logga in, Skapa konto, Exempel m.fl.) finns som enkla platshållare och byggs ut i kommande steg.
